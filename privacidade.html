Como tratamos

👁️ O que coletamos

O Fortaleza Sub & Via é um projeto estático sem servidor próprio de aplicação. Não utilizamos formulários com backend, não armazenamos dados em banco de dados próprio e não criamos contas de usuário.

Dados que podem ser coletados indiretamente:

  • Dados de acesso (IP, navegador, páginas visitadas) pelo provedor de hospedagem, para fins estatísticos agregados.
  • Dados enviados pelo formulário de contato: nome, e-mail e mensagem — transmitidos diretamente via cliente de e-mail do usuário para jooclaudiano@gmail.com. Esses dados não passam por servidor intermediário do projeto.

🍪 Cookies e rastreamento

O site não utiliza cookies próprios para rastreamento ou marketing. Nenhum script de analytics de terceiros (Google Analytics, Hotjar, Meta Pixel) está instalado neste projeto.

A biblioteca Leaflet.js (mapa interativo) e o Chart.js são carregados de CDNs externas (unpkg, jsdelivr). Esses CDNs podem registrar seu IP por questões técnicas de entrega de conteúdo, conforme suas próprias políticas.

📧 Formulário de contato

O formulário da página de contato usa o protocolo mailto:, que abre o cliente de e-mail padrão do usuário. A mensagem é enviada diretamente do seu dispositivo para o e-mail do projeto, sem passar por servidores intermediários.

As informações enviadas (nome, e-mail, mensagem) são usadas exclusivamente para responder ao contato e, quando autorizado, creditar contribuições de dados no acervo.

🔗 Links externos

O projeto contém links para sites de terceiros (Diário Oficial, G1, Diário do Nordeste, instituições acadêmicas). Não temos controle sobre as políticas de privacidade dessas plataformas. Recomendamos que você verifique as políticas de cada site antes de fornecer dados pessoais.

⚖️ Seus direitos (LGPD)

Em conformidade com a Lei Geral de Proteção de Dados (Lei nº 13.709/2018), você tem direito a:

  • Solicitar confirmação sobre o tratamento de seus dados pessoais;
  • Solicitar correção de dados incompletos, inexatos ou desatualizados;
  • Solicitar a exclusão de dados pessoais desnecessários ou tratados em desconformidade com a LGPD;
  • Revogar o consentimento a qualquer momento.

Para exercer seus direitos, entre em contato pelo e-mail jooclaudiano@gmail.com.

🔄 Alterações nesta política

Esta política pode ser atualizada periodicamente. As alterações entram em vigor na data de publicação e serão indicadas na data de "última atualização" no topo da seção. Para dúvidas, entre em contato.
